HOW TO MAKE THE .EXE (Windows)
1. Install Python 3.10-3.12 from python.org (tick "Add python to PATH").
2. Double-click  build_exe.bat   (takes 2-5 minutes, needs internet once).
3. Your game: dist\SpicyJohn\SpicyJohn.exe  -> right click > Send to > Desktop (shortcut).
Keep the whole SpicyJohn folder together (the exe needs the files next to it).
If Windows SmartScreen warns: More info > Run anyway (normal for unsigned games).
